Version: 0.9.0
Date: 2026-10-25
  Features:
    - New startup setting "Every armor flies (wings)": every armor lets its wearer fly over
      buildings, cliffs and water, like Space Age's mech armor, so winged avatars can take to the
      air. Armor that flies this way has a small feather on its icon. Only the item icons
      change; the armor looks the same on the character. Off by default.
      Needs Space Age: without it, Factorio allows no flying armor and the setting does nothing.

---------------------------------------------------------------------------------------------------
Version: 0.8.0
Date: 2026-10-25
  Features:
    - Avatars sprint when their armor makes them fast: with two or more exoskeletons (a movement
      bonus of 60 % or more), the avatar runs with long bounding strides instead of a quick jog.
      The map setting "Sprint from this armor speed bonus" changes the threshold; 0 turns sprinting
      off. The switch happens when the armor or its equipment changes, once nothing is open.
    - Packs exported with Factorio Avatar Exporter 0.21.0 or newer have the sprint; older packs
      keep working and always jog.
---------------------------------------------------------------------------------------------------
Version: 0.7.0
Date: 2026-10-24
  Changes:
    - The internal name is now vrc-avatars, the same as the name shown in the game, so the file is
      vrc-avatars_<version>.zip. Avatar packs are now named vrc-avatar-<id> (the file
      vrc-avatar-<id>_1.0.0.zip). Packs made before this, and the old avatar-characters mod, don't
      work with it: remove them and export your avatar again with exporter 0.20.0 or newer.
      Before updating a save, run /avatar-revert-all in it with the old mods installed.

Version: 0.5.2
Date: 2026-10-24
  Bugfixes:
    - Mining swings at the engineer's pace. A pack that doesn't set its own mining speed was played
      at the speed meant for a 12-frame swing, so the exporter's 26-frame swing took more than twice
      as long; the default now scales with the number of frames.

Version: 0.3.0
Date: 2026-10-23
  Features:
    - Avatar bundles (mods named avatar-bundle-<name>): several avatar packs in one mod, so a server
      hands every player one file. Make one with Combine Packs in the Factorio Avatar Exporter. A
      character keeps its name whether it comes as a pack or in a bundle, so a save keeps everyone's
      characters when a server switches.

Version: 0.1.0
Date: 2026-10-23
  Features:
    - First version. Every player picks their own look from the installed avatar packs (mods named
      avatar-pack-<id>, made with the Factorio Avatar Exporter for Unity), or stays the engineer.
    - /avatar-revert-all [pack id] turns everyone back into the engineer, or only those using one
      pack, so the mod or a pack can be removed without losing characters.
    - Remote interface "avatar-characters" for other mods.
  Info:
    - Grew out of the Dragon Character mod (0.2.2), without the dragon. Avatar packs made for it
      (dragon-avatar-<id>) need to be exported again.
