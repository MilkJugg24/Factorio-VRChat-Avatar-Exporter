---------------------------------------------------------------------------------------------------
Version: 0.6.0
Date: 2026-10-24
  Changes:
    - Renamed to VRC Avatars. Its internal name stays avatar-characters, so saves and avatar packs
      keep working.
---------------------------------------------------------------------------------------------------
Version: 0.5.2
Date: 2026-10-24
  Bugfixes:
    - Mining swings at the engineer's pace. A pack that doesn't set its own mining speed was played
      at the speed meant for a 12-frame swing, so the exporter's 26-frame swing took more than twice
      as long; the default now scales with the number of frames.
---------------------------------------------------------------------------------------------------
Version: 0.5.1
Date: 2026-10-24
  Changes:
    - The avatar window's text no longer mentions bundles: a server simply installs every player's
      avatar pack. Bundles made earlier still load.
---------------------------------------------------------------------------------------------------
Version: 0.5.0
Date: 2026-10-24
  Features:
    - An animation of a pack may set its own pixels_per_tile, to be drawn at that resolution: the
      exporter (0.10.0 on) draws an animation too large for the sprite sheets at half resolution,
      the same size in the game. Its packs need this version.
---------------------------------------------------------------------------------------------------
Version: 0.4.1
Date: 2026-10-24
  Bugfixes:
    - The footstep sound plays on every step of an avatar's run, not every second one, and the
      footprints fall on the avatar's own footfalls.
---------------------------------------------------------------------------------------------------
Version: 0.4.0
Date: 2026-10-24
  Features:
    - Packs may split a sheet whose row of frames is too wide for one file by frames
      (frames_per_file), each file holding every direction. Exporter 0.7.0 does this for its longer
      idle animations, so its packs need this version.
---------------------------------------------------------------------------------------------------
Version: 0.3.2
Date: 2026-10-23
  Changes:
    - The avatar window lists the looks one per row, each with its name and author, so similar avatars
      can be told apart; click the button or the name. It shows four rows before it scrolls, never part
      of one.
---------------------------------------------------------------------------------------------------
Version: 0.3.1
Date: 2026-10-23
  Bugfixes:
    - The avatar window opens in the middle of the screen. It hung from the middle before, and on a
      small screen its Done button was cut off.
---------------------------------------------------------------------------------------------------
Version: 0.3.0
Date: 2026-10-23
  Features:
    - Avatar bundles (mods named avatar-bundle-<name>): several avatar packs in one mod, so a server
      hands every player one file. Make one with Combine Packs in the Factorio Avatar Exporter. A
      character keeps its name whether it comes as a pack or in a bundle, so a save keeps everyone's
      characters when a server switches.
---------------------------------------------------------------------------------------------------
Version: 0.2.0
Date: 2026-10-23
  Changes:
    - For Factorio 2.1, which no longer loads mods made for 2.0. Avatar packs need to be made for 2.1
      as well: export them again with Factorio Avatar Exporter 0.3.1 or newer.
---------------------------------------------------------------------------------------------------
Version: 0.1.0
Date: 2026-10-23
  Features:
    - First version. Every player picks their own look from the installed avatar packs (mods named
      avatar-pack-<id>, made with the Factorio Avatar Exporter for Unity), or stays the engineer.
    - /avatar-revert-all [pack id] turns everyone back into the engineer, or only those using one
      pack, so the mod or a pack can be removed without losing characters.
    - Remote interface "avatar-characters" for other mods.
  Info:
    - Grew out of the Dragon Character mod (0.2.2), without the dragon. Avatar packs made for it
      (dragon-avatar-<id>) need to be exported again.
